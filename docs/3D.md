# 3D and motion

One tweening library: GSAP (free since 2025, includes ScrollTrigger). TresJS for the scene. Both loaded lazily inside `<ClientOnly>` after first paint; the hero renders its static PNG first, then swaps in the canvas.

## Day hero: `Hero/PageExploded`
Asset: `public/models/page-exploded.glb` (made in Claude Design with the prompt in `docs/PROMPT-3D.md`). If the delivered file uses other mesh names, rename with `gltf-transform` before committing; never patch names at runtime.

Expected hierarchy:
```
page_root
  layer_01_nav
  layer_02_hero
  layer_03_cards
    card_a  card_b  card_c
  layer_04_code
  layer_05_footer
```
Units: 1 = page width. +Y up, page faces +Z, origin at the assembled page center. Pivots centered.

Explode offsets (position.z at scroll 100 %): nav 0.55, hero 0.40, cards 0.25 (plus x fan: a -0.06, c +0.06), code 0.12, footer 0. Ease `power2.out`, scrub 0.6.

Behavior:
- Scroll: `ScrollTrigger` pinned to the hero section, `start: 'top top'`, `end: '+=100%'`; scrub each layer's `position.z` from 0 to its offset. Guide lines (thin cylinders or a line material) fade in from 60 %.
- Idle: `page_root` floats ±0.02 in y over 6 s, `sine.inOut`, always on.
- Hover: pointer position over the stage tilts `page_root` up to 8° on x/y, 300 ms `power2.out`; returns on leave.
- Reduced motion or `pointer: coarse`: no scroll scrub, no tilt; render one frame assembled, or use the PNG.
- Fallback: `public/models/page-exploded.png` (assembled render on `--bg`) for mobile, reduced motion, WebGL failure, and as the LCP image while the GLB loads.

Lighting: one directional key from top-left, one soft fill, ambient 0.6, all matte materials from the GLB. No environment map (keeps the bundle small).

Budget: GLB under 300 KB after `gltf-transform optimize`; three + TresJS chunk under 200 KB gzipped, loaded after `onNuxtReady`.

## Night hero: `Hero/MoonStage`
No GLB. Procedural scene:
- Sphere (radius 0.9) at top-right with an emissive warm material (`--accent`) and a large soft point light; two glow ellipses drawn as CSS behind the canvas (see F-Home-Film hero SVG: 260 px and 90 px radii at 9 % and 12 %).
- Three planes (2.39:1, rounded via alpha mask) textured with the first three stills of the featured film from the manifest, stacked in depth at z 0, -0.6, -1.2 with 10 % scale steps; the front one shows the muted preview video if available.
- Pointer parallax: planes shift up to 12 px, opposite to the pointer, 400 ms.
- Grain: CSS overlay, 6 % opacity noise PNG, `mix-blend-mode: overlay`.
- Fallback: static composite (poster + glow) as PNG.

## Mode transition (`useModeTransition`)
1. Read the toggle knob center.
2. Snapshot: add class `mode-switching` to html (disables transitions on children).
3. Set `data-mode` to the target and animate `clip-path: circle(0 at x y)` to `circle(150% at x y)` on a full-screen overlay that holds the previous mode's colors, 700 ms `--ease-out`. At 50 % swap the display font (already automatic through tokens).
4. Remove the overlay, announce via `aria-live`.
Reduced motion: cross-fade 150 ms.

## Other motion
- Card hover: translateY -2 px, border color to `--accent` at 40 %, 240 ms.
- More tile hover: the three stacked ghost cards fan out (rotate -4°, 0, 4°), arrow slides 4 px right.
- Filmstrip: native horizontal scroll with `scroll-snap`, no JS carousel.
- Testimonials single: crossfade 300 ms, auto-advance 8 s, pauses on hover and focus, dots are buttons.
- FAQ: height auto animation with `grid-template-rows` trick, 240 ms.
- Page transitions: keep the existing Nuxt page transition (fade 200 ms).
